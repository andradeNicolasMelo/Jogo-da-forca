# Jogo da Forca
![](https://imgur.com/nIZFgts.gif)

Este é um jogo da forca feito em C# para rodar no console, com recursos extras que tornam a jogabilidade mais interessante e desafiadora.

## Funcionalidades do Jogo

✅ **1. Letras já digitadas**  
O jogo armazena o histórico de letras já chutadas. Se o jogador tentar repetir uma letra, será avisado e deverá digitar outra.

✅ **2. Validação de tentativas**  
Não é permitido repetir letras já chutadas. Isso evita jogadas inválidas e força o jogador a pensar melhor antes de tentar novamente.

✅ **3. Escolha de categoria**  
Antes de iniciar a partida, o jogador escolhe uma categoria de palavras:
- Frutas
- Animais
- Países

A palavra secreta será sorteada da categoria escolhida.

✅ **4. Tentativa com palavra inteira**  
O jogador pode tentar adivinhar a palavra inteira de uma vez.  
- Se acertar, vence na hora.  
- Se errar, leva uma penalidade como se fosse um erro normal.
